# Vibe Coding

A collection of projects built using AI assisted and prompt driven development workflows.

These projects explore practical applications across web development, automation, analytics and AI, with development supported by tools such as Google AI Studio, Gemini and other AI coding workflows.

## Projects

### SoulCity Bhakti Radio

A devotional radio web application built for GTA RP communities.

Features include:

- Aarti, Bhajan, Mantra, Chalisa and Stotram
- Daily devotional content
- YouTube and direct audio playback
- Search and playlists
- Navratri experience with dynamic themes
- Community song suggestions
- Firebase backed music library
- Private admin management
- AI assisted YouTube playlist classification
